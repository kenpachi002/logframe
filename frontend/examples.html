CEF — Common Event Format

ArcSight standard adopted widely across network security. Pipe-delimited header with key=value extension fields. Used by Cisco, Palo Alto, Fortinet, Juniper, Check Point and many more.

Cisco ASAPalo Alto PAN-OS Fortinet FortiGateJuniper SRX Check PointArcSight

Syslog — RFC 3164 & RFC 5424

The universal logging protocol for Unix/Linux systems, network infrastructure, and security appliances. Priority encoded as <facility×8+severity>. RFC 5424 adds structured data blocks.

Linux Kerneliptables OpenSSHCisco IOS RFC 3164RFC 5424
